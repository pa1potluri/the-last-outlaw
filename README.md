## Browser loading and display

The root page shows title artwork and real loading progress immediately, then
reveals the game in the same frame. Desktop keeps its fitted playfield. Phones fill the landscape screen with
translucent stick, Jump, Shoot and Pause overlays. Tap WEAPON to switch guns,
tap MISSION to use a nearby objective, and change Sound On/Off in Pause.

## itch.io upload settings

Upload `outputs/the-last-outlaw-itch.zip` as an HTML Game and mark the ZIP as
"This file will be played in the browser". Enable Mobile Friendly and use
landscape orientation. Keep Click to Play enabled and Scrollbars disabled.
Use Click to launch in fullscreen, or enable Fullscreen Button for an in-page
embed. The game resizes to the available screen and pauses in portrait.

Phone controls: drag the stick left/right, push farther to sprint, flick up/down
to change lanes, hold Shoot, and tap Jump. Tap WEAPON to switch guns and MISSION
to interact. Sound controls are in Pause. Desktop controls remain unchanged.

Release checks use Chrome phone emulation and desktop browser tests; physical
phone and Safari testing have not been performed. See the developer handoff for
full validation details.
